# Scope

## In scope
1. One Zoho service: Zoho People.
2. Conversational/text prompt backend.
3. Orchestrator.
4. Zoho People API integration.
5. OAuth/token lifecycle.
6. Rate-limit awareness and throttling.
7. Caching for frequently used data/configuration.
8. Validation, errors, structured logging, request IDs.
9. Deployable Zoho Catalyst backend.

## Out of scope for first POC
- CRM/Projects integrations.
- Production-grade multi-tenant billing.
- Full voice streaming UI.
- Complex autonomous agent loops.
